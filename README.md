# رحلتي مع القرآن (نموذج أولي)

لوحة متابعة قراءة القرآن: عربية، تعمل بدون إنترنت، وتحفظ في المتصفح.
تدعم مصحفين: المدينة (604 صفحة) والشمرلي (521 صفحة، الفاتحة ص1 بلا الغلاف).

- `index.html`: الملف الجاهز للنشر (ناتج البناء).
- `src/template.html`: مصدر التطبيق. `data/editions.json`: حدود السور والأجزاء والأرباع لكل طبعة.
- `python3 tools/build.py`: يعيد بناء `index.html`.
- بيانات المدينة من حزمة quran-meta، وبيانات الشمرلي من قاعدة بيانات تطبيق الشمرلي مفتوح المصدر (انظر `tools/`).
- الشمرلي: حدود بعض الأرباع قد تختلف صفحة واحدة؛ تحتاج مراجعة على المصحف المطبوع.
- الخطوة التالية: مشروع Vite منظم، ثم Supabase لتسجيل الدخول.
